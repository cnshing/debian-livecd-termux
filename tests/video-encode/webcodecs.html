WebCodecs hardware encoding colour probe

Use ?codec=avc1.42001f&input=canvas or ?codec=vp09.00.10.08&input=bt709. Each run encodes 60 frames at 640×360, 30 fps and 2 Mb/s constant bitrate, then requests software decode. BT.709 input is a diagnostic control; canvas input must pass before enabling defaults. Serve on localhost or HTTPS. The launcher must select a private hardware encoder session. Optional save=1 posts encoded chunks to a server's /chunks endpoint.
